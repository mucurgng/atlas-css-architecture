# Конверты стресс-теста: задания без предварительного решения

Преподаватель/рецензент выбирает один конверт. На выполнение 15–20 минут. Допускается работа только в исходниках без отключения тестов. Для сдачи нужны commit/diff, короткое объяснение каскада и повторный прогон проверок.

## Конверт A. Новый статус «Приостановлено»

Добавьте `ui-tag--paused` и `ui-alert--paused` с единым семантическим цветом в обеих темах. Нельзя делать один глобальный `.is-paused`, который задаёт background всем семействам. Доказать независимость двух компонентов.

## Конверт B. Большой текст

Заказчик включил локализацию: текст в первой карточке стал длиной 200 символов без пробелов, а текст кнопки — до 100 символов. Проверить 320/375 px и отсутствие горизонтального overflow. Изменить только минимально необходимые стили.

## Конверт C. Кнопка на всю ширину карточки

По мобильному макету кнопка внутри `.ui-card` должна иметь 100% ширины при размере контейнера до 400 px и оставаться auto при остальных размерах. Не менять кнопки вне карточки. Желательно использовать контейнерный запрос, обосновать альтернативу.

## Конверт D. Чужой stylesheet v2

Интегратор принёс новый файл со стилем `.ui-button { border-radius: 0; }`. Включите его так, чтобы новая библиотека сохранила свой контракт, а внешняя панель имела свой вид. Запрещено удалять новый CSS; обоснуйте слой, область и приоритет.

## Конверт E. Смена роли токена

Дизайнер меняет акцент и поверхности в тёмной теме. Внесите изменение только в таблицу токенов, без правок во всех семи компонентах. Проверьте контраст текста и disabled/focus states.

## Конверт F. Режим reduced-motion

Добавьте в карточки плавное движение при hover, но пользователи с prefers-reduced-motion: reduce должны видеть неподвижный вариант. Докажите выполнение через DevTools Rendering/браузерный тест.

## Конверт G. Дополнительная вложенность

В карточку с уведомлением добавьте вторую вложенную карточку. Объясните, какие стили внешней карточки имеют право воздействовать на внутреннюю, а какие нарушают контракт. Доработайте селекторы, если необходимо.
