# ATLAS UI · CSS Architecture Rescue

**Учебный проект содержит намеренные ошибки.** Это заготовка, а не готовое решение.

## Запуск

1. Установите Node.js 18 или новее.
2. В терминале из корня проекта: `npm run dev` (никаких зависимостей для запуска не нужно).
3. Откройте `http://127.0.0.1:5173` в современном браузере.
4. Выполните `npm test` — часть тестов ДОЛЖНА не пройти до исправления.
5. Не открывайте HTML через `file://`: используйте локальный сервер.

## Браузерные тесты (дополнительно)

```bash
npm install --save-dev @playwright/test
npx playwright install chromium
npm run test:e2e
```

> Первые запуски могут требовать подключения к интернету для загрузки Playwright и браузера.

## Цель

Спроектировать предсказуемый каскад, устранить дефекты, реализовать состояния 7 семейств компонентов и подтвердить отсутствие регрессий. Работа высокого уровня: важнее обоснованное решение, чем визуальная косметика.

## Работать в основном с

- `css/app.css` — объявление слоёв, импорты;
- `css/legacy.css` — чужой CSS; нельзя удалять сам виджет;
- `css/components.css` и `css/states.css` — компоненты, состояния;
- `css/tokens.css` — семантические токены и темы;
- `js/app.js` — минимальные интеракции, диалог, валидация;
- `index.html` — семантика, корректные состояния и примеры.

## Артефакты сдачи

1. Ссылка на GitHub с коммитами до и после рефакторинга.
2. Заполненные `reports/AUDIT_TEMPLATE.md`, `reports/MATRIX_TEMPLATE.csv`, `reports/ADR_TEMPLATE.md`, `reports/REGRESSION_TEMPLATE.md`.
3. `npm test` без провалов и браузерные проверки (Playwright / ручной чек-лист).
4. Скриншоты на 320, 375, 768, 1024, 1440, 1920 px + две темы.
5. Видео не требуется; демонстрация работы и неожиданная правка на защите обязательны.

## Принцип честной проверки

Не разрешается просто удалять сложные компоненты/разметку, менять проверки для получения зелёного результата, отключать стили vendor, вставлять `!important`, скрывать горизонтальное переполнение на `body` без устранения причины.
